# Something Isn't Adding Up — CIT 140

## Week 1 Investigation

This repository contains my CIT 140 Week 1 Systems Analysis and Design investigation materials for the case **"The Process Below"** involving Meridian Forge Robotics.

### Folder Organization

All Week 1 materials are located in:

`Week01_Something_Isnt_Adding_Up`

Inside the Week 1 folder:

- **Evidence** — Contains the case evidence records and evidence classification materials.
- **Notes** — Contains my investigation notes and working notes from reviewing the case records.
- **Artifact** — Contains my completed Problem Brief PDF.

### Evidence

The Evidence folder contains the case records reviewed during the investigation, including:

1. Incident Log
2. Current Scheduler
3. Maintenance Record
4. Command Telemetry
5. Staff Statements

The evidence classifications distinguish between **facts, assumptions, and open questions** based on what each source directly supports.

When a case document is provided as a **RAW** document, the RAW file is downloaded and saved in the Evidence folder so the original case material is preserved.

### Notes

The Notes folder contains my investigation notes, including:

- Incident summary
- Evidence reviewed
- Verified findings
- Evidence classifications
- Questions that still need investigation
- Important distinctions between verified information and assumptions

### Artifact

The Artifact folder contains the final **Week 1 Problem Brief PDF** submitted for the investigation.

### Important Investigation Distinction

The investigation does not assume that `legacy_sync.exe` caused the entire incident. The available telemetry identifies it as a source label, but additional evidence is needed to determine the broader cause.

The investigation also does not recommend a solution. Additional evidence gathering is needed before determining how the issue should be addressed.
